# # Code Reviewer AI - AI-Powered Code Review SaaS

An intelligent code review platform using Google's Gemini AI to analyze code for security vulnerabilities, performance issues, code quality, and bugs.

## Features
- 🤖 AI-powered code analysis using Gemini
- ⚡ Real-time code reviews
- 🎨 Beautiful UI with Next.js
- 🔧 FastAPI backend
- 📊 Clean & intuitive interface

## Tech Stack
- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Backend:** FastAPI, Python
- **AI:** Google Gemini API
- **Deployment:** Vercel (Frontend), Railway (Backend)

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

Visit http://localhost:3000
